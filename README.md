# Verdure

A procedural 3D forest hidden inside a translucent stone.

Verdure is an interactive WebGL experiment inspired by moss agate, dendritic inclusions, miniature landscapes and the peculiar feeling that a tiny object might contain somewhere impossibly large.

The experience begins outside the specimen. Turn it in your hand, watch the forest catch the light, then enter it. The moss-like inclusions resolve into trees, fog banks and terrain. Scale becomes unreliable on purpose.

## Design principles

- Serenity before spectacle.
- Procedural generation should feel organic, not evenly random.
- Empty space is part of the forest.
- The stone is a threshold, not a decorative frame.
- UI should stay almost invisible.
- No downloaded 3D assets are required for the core scene.
- A seed must reproduce the same world.
- Motion and audio must respect user preferences.

## Stack

React, TypeScript, Vite, Three.js and React Three Fiber.

## Status

The first playable specimen is being built directly in this repository.
